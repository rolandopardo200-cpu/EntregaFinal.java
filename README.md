# Segunda entreg 

Proyecto desarrollado en Java 8 para la generacion y procesamiento
de archivos de informacion de productos, vendedores y ventas.

## la Estructura del proyecto que hicimos

El ejericio tiene:

- `GenerateInfoFiles.java`: genera archivos de prueba
- `main.java`: procesa los archivos de entrada y genera los reportes
- `Producto.java`: informacion de un producto
- `Vendedor.java`: informacion de un vendedor
